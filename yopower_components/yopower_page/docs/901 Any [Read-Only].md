# Any (Read Only)

- ✅ Any column type
- ⚠️ No json parameters (the plugin clears `yp_parameters` on save)
- Makes an editable column read-only on the grid: the value is displayed as plain text and clicks / key presses do not enter edit mode.
- Combine with **Conditions** to lock a column only for some rows (i.e. closed records).
