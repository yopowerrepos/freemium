# Any (Color By Hex)

- ✅ Any column type
- ⚠️ The column defined on the json parameters should be on the view
- The cell keeps its own value and uses the text column informed on `column` as background color.
- The color column should store a CSS color, i.e. `#FF0000` (any valid CSS color works).

## Parameters

```json
{
  "column": "yp_hexadecimal"
}
```
